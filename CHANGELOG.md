# Changelog

## 1.0.0

Out of alpha!

- SEQ: enter a page's notes one at a time, no playing along. KNOB 2 sets how long a note is
- LFO is undo
- Four demo songs: Tetris, Mountain King, Fur Elise and Toccata. They're locked so you can't lose them, and GLO + HOME has a menu to restore them
- Punch-in FX: 16 pads, tape stop, echo, reverb, solo and more
- Live recording, the tape dial, and a Game Boy wave editor
- Long notes show a line under them
- Delete a project and it asks first
- Little animations. Leave it alone for a bit and see
- On the site: Play online, a tutorial that builds the Tetris theme, and a cheat sheet you can print

## 0.1.0-alpha

First release.

- NES, Game Boy and Master System sounding chips. Based on schematics, so pretty close!
- The rack
- tone and envelope pages per chip (ooh la la)
- 8 projects! that's so many!
- HELP! what a cool feature. Press GLO on any page.
